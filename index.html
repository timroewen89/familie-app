    Instellingen

    Google Calendar

    Maak in de Google Cloud Console een OAuth Client-ID (webapplicatie) aan. Zie de README voor stap-voor-stap instructies. De Client-ID wordt alleen lokaal in je browser bewaard.

    Picnic (optioneel)

    Vul de URL van je eigen Picnic-proxy in (zie de README, sectie "Picnic koppelen"). Je logt daarna in met je eigen Picnic-account; het wachtwoord wordt nooit bewaard.

    Agenda's

    Kies welke agenda's uit je Google-account in het overzicht meedoen.

    Inloggen bij Picnic

    Log in met je eigen Picnic-account. Je wachtwoord wordt direct en versleuteld naar Picnic gestuurd en nergens opgeslagen; alleen het inlogtoken blijft in je browser.

    Verificatiecode

    Picnic heeft een code naar je telefoon gestuurd (SMS). Vul hem hieronder in.
